Commonplace Connector Settings

Configure how the extension integrates with your personal research workspace.

Connection Settings

Enter the URL where your Commonplace app is running. For local development, this is typically http://localhost:8080/index.html, http://localhost:5500/index.html, or http://127.0.0.1:8080/index.html.

Focus existing tab/PWA: If Commonplace is already open, the extension will bring it to the front, switch to it, and open the "Add Article" dialog. If it is not open, it will launch in PWA style.
Standalone window: Opens Commonplace in a chromeless window without browser tabs or address bar, mimicking a native desktop application.

Usage Instructions

Adding Articles

  • Extension Button: Click the extension icon in your toolbar to open a preview popup. Customize the title, URL, and select "Article" or "Tweet", then click "Add to Commonplace".
  • Keyboard Shortcut: Press Cmd+Shift+Y (Mac) or Ctrl+Shift+Y (Windows/Linux) to instantly capture the current page.
  • Context Menu: Right-click anywhere on a webpage to add the page, or right-click a link to add that link.

Local Files (file:/// URLs)

If you run Commonplace directly by opening the index.html file in your browser, you must grant the extension permission to access file URLs:

  1. Open the extensions management page (Firefox: about:addons, Chrome: chrome://extensions).
  2. Find Commonplace Connector and click details/preferences.
  3. Toggle on "Allow access to file URLs" (Chrome) or check relevant permission boxes.
